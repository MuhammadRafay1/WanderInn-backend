WanderInn Backend
Welcome to WanderInn Backend, a RESTful API designed to power the WanderInn platform. WanderInn is a platform that allows users to book stays at various properties like apartments, hotels, and more.

Features
User authentication and management.

Property listings with detailed information.

Booking management (create, update, delete).

Payment integration.

Reviews and ratings for listings.

Admin features for managing users and properties.

Technologies Used
Node.js: JavaScript runtime for building the backend.

Express.js: Web framework for Node.js to handle HTTP requests.

MongoDB: NoSQL database to store user and listing data.

Mongoose: MongoDB object modeling for Node.js.

JWT: JSON Web Tokens for authentication.

Bcrypt: For password hashing.

Cloudinary: For image uploads.

Installation
Prerequisites
Node.js and npm installed on your machine.

MongoDB Atlas or a local MongoDB instance.
